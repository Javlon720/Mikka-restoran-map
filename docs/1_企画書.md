# 飲食店情報口コミサイト「Mikka」企画書

**提出日:** 2026年6月30日
**開発者:** Javlon (日本就業素養・コワーク授業 補講対象者)
**対象テーマ:** テーマ② 飲食店情報口コミサイト

---

## 1. 企画背景と目的
JDU（Japan Digital University）の学生およびウズベキスタン在住の外国人が、ウズベキスタン国内（または日本国内）の飲食店情報を簡単に検索し、多言語で口コミを共有できるプラットフォーム「Mikka」を企画しました。
本プラットフォームは、言語の壁を越えて美味しい飲食店を見つけられるようにし、さらにAIを活用したチャットボットによって、個人の好みに合わせた店舗提案を行うことを目的としています。

## 2. ターゲットユーザー
- ウズベキスタンに住む日本語学習者・日本人駐在員・観光客
- 多言語（ウズベク語、日本語、英語、ロシア語）で飲食店の情報を得たい人々
- 自分の好みに合った飲食店をAIアシスタントと対話しながら探したいユーザー

## 3. アプリケーション概要
「Mikka」は、インタラクティブな地図（Leaflet）とモダンなユーザーインターフェースを備えた、プレミアムな飲食店情報口コミWebアプリケーションです。

### 主な特徴:
- **多言語対応 (i18n):** ウズベク語・英語・ロシア語・日本語の4言語をワンクリックで切り替え可能。
- **インタラクティブマップ:** 地図上のピン（マーカー）から直感的に店舗の場所を把握し、詳細情報を確認できます。
- **Mikka AI Assistant:** Gemini APIを搭載したAIチャットボットが、ユーザーの質問（「おすすめのウズベク料理は？」「評価の高い店は？」など）にリアルタイムで回答します。
- **管理者と一般ユーザーの権限分離:** 管理者は店舗のCRUD操作が可能、一般ユーザーは口コミの投稿・編集・削除が可能です。

## 4. 機能要件 (必須要件の網羅)

| 番号 | 必須機能要件 | Mikkaでの実装内容 |
| :--- | :--- | :--- |
| 1 | 飲食店情報の登録・編集・削除 | 管理者画面から店舗名、料理ジャンル、住所、説明、画像を登録・編集・削除可能 |
| 2 | 飲食店の口コミ情報の登録・編集 | ログインユーザーが5段階評価、コメント、画像付きで口コミを投稿・編集可能 |
| 3 | 他人からの口コミ情報の表示 | 店舗詳細画面にて、他のユーザーが投稿した口コミを一覧表示（編集・削除制限付き） |
| 4 | 多言語対応 | ウズベク語、英語、ロシア語、日本語に対応。UI表示を動的に翻訳切り替え |
| 5 | 口コミ情報（店舗情報・画像・地図） | 店舗の住所、説明、アップロード画像に加え、Leaflet.jsによる地図情報（緯度・経度）を登録表示 |
| 6 | 管理者機能 | 管理者ロール of ユーザーのみ、飲食店情報の追加・編集・削除ボタンを表示し、実行可能にする |
| 7 | 利用者登録・ログイン | メールアドレス/パスワードによる新規登録・ログイン機能、Google OAuthログインの統合 |
| 8 | 口コミ情報（店舗）の検索 | 店舗名、料理ジャンル、住所などのキーワードによるリアルタイム検索機能 |
| 9 | 魅力的なサイトデザイン | Glassmorphic（半透明）デザイン、Google Fonts (Inter)、レスポンシブな2カラムレイアウト（グリッド＆マップ）を採用 |

## 5. 期待される効果
- **外国人ユーザーの利便性向上:** 言語が分からなくても、自分の母国語で飲食店を探し、レビューを書くことができます。
- **インタラクティブな体験:** 地図とAIアシスタントとの対話により、従来のテキスト主体の口コミサイトより楽しく直感的に店舗を探せます。
- **店舗集客 of 支援:** 正確な位置情報とリアルタイムの口コミにより、優良な店舗が外国人コミュニティに認知されやすくなります。
