# 飲食店情報口コミサイト「Mikka」作業スケジュール（作業行程表）

**提出日:** 2026年6月30日
**開発者:** Javlon (日本就業素養・コワーク授業 補講対象者)
**対象テーマ:** テーマ② 飲食店情報口コミサイト

---

## 1. 開発プロセス概要
本プロジェクトは、2026年6月1日から6月30日までの約4週間（1ヶ月）で、設計、データベース構築、バックエンドAPI開発、フロントエンド画面構築、外部API（地図、Google Auth、Gemini）連携、テスト、ドキュメント作成を体系的に進めました。

## 4. 進捗報告とコワーク活動
- **週次報告:** コワーク授業および報告会向けに、週次の作業進捗（バックエンドAPI完了、フロントエンド完了、AI連携完了など）を都度整理し、自己管理を行いました。
- **環境準備:** ローカル環境に PostgreSQL、Vite、Node.js（pnpm workspaces）の環境を各自で構築し、依存パッケージの管理とビルドを独立して実施できるようにしました。
